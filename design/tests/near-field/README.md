# 近场传感器台架测试记录

整理日期：2026-09-03。对象：ESP32、URM09-I²C（SEN0304）×1、VL53L1X ×2。

本目录归档组员提供的实际串口日志、接线核验依据和分析结果。现阶段已取得三只传感器分别进行台架测距的证据；左右 ToF 在同一份日志中运行。尚无三路同时采集、固定距离标定或传感器触发整车制动的完整记录。

| 对象 | 记录数 | 程序判为有效 | 有效率 | 本次判断 |

| 左 VL53L1X，0x2A | 1657 | 1655 | 99.88% | 基础测距运行正常，2 次单帧无效后恢复 |

### 复算

在主仓库根目录运行 Python 3，无第三方依赖：

```bash
python design/tests/near-field/summarize.py
```

[统计脚本](summarize.py) 检查每条记录格式、通道地址、状态分类和单通道时间戳递增，输出记录数、有效率、距离极值、采样间隔、状态码计数、连续无效区间和文件摘要。无法识别的非空行会报错，不会静默丢弃。

统计口径：

- 有效率 = 程序有效记录数 / 该通道全部记录数；分母包含无效记录。
- 有效距离范围仅统计有效记录，不使用无效记录中的原始距离。
- 单路采样率 = 1000 / 该路相邻时间戳差的平均值；ToF 按左右分组，不能把两路交替打印间隔当成单路周期。
- 连续无效段按单路记录顺序定义；段内跨度 = 最后无效时间 − 首个无效时间。单帧跨度为 0 ms，不代表无需等待恢复。
- 脚本同时输出前后有效样本时间；这两个有效样本之间的间隔更适合描述可用数据中断。尾部没有恢复样本时保持空值。
- 超声波“局部远距离跳变”筛选：连续三条均为 `VALID`，中间距离大于 100 cm 且大于前后均值的 2.5 倍。这只是复查线索，不是误测真值或已部署滤波器。
