# 购物车三路测距扩展协议 R3-V1

日期：2026-09-05。状态：接口已按本轮方案确定，交付下位机同学实现；尚未烧录或完成联调。

本协议是 V1 的独立兼容扩展，不实施旧 V2 草案的三轴运动、侧移、舒适距离配置或 risk_mask。当前 Android 修复仍使用旧固件与 c 指令；三路解析、诊断和运动决策后续分阶段接入。

## 1. 能力与旧版兼容

既有 f、h、c、s、!S 指令及回复保持原语义，包括 s<cm> 最小距离。完整实现本协议后，能力回复为：

```text
fCART_AT8236:s:r3v1:
```

实际报文均以 LF（\n）结尾。旧 Android 仍发送 s100；新 Android 仅发现 r3v1 后启用扩展，未启用不得主动发送新增报文。

## 2. 启停

```text
!R3,<period_ms>
!R3,OK,<period_ms>
```

第一行是请求，第二行是回复。0 关闭；非零为 100～1000 ms 的十进制整数，Android 默认请求 100 ms。缺字段、多字段、非整数、越界回复 !ERR,bad_r3_config，保持原配置。重复配置幂等，不重置序号。

三路与旧 s 上报独立；新 Android 可先发 s0 再启用三路。BLE 断连或重启后关闭三路；USB 配置仅影响 USB。配置和查询不得取得运动控制权、刷新运动看门狗、解除停车或故障；停车状态仍可读取遥测。OK 仅确认配置，不代表传感器有效或允许运动。

## 3. 快照

```text
!R3D,<seq>,<emit_ms>,<L_mm>,<L_status>,<L_age_ms>,<C_mm>,<C_status>,<C_age_ms>,<R_mm>,<R_status>,<R_age_ms>
```

| 字段 | 定义 |
|---|---|
| seq | 各输出通道独立 uint16，每生成快照加一；65535 后为 0；重启或新 BLE 连接从 0 开始 |
| emit_ms | 快照生成时的 ESP32 开机毫秒 uint32，允许自然回绕 |
| L/C/R | 车体固定左／中／右传感器编号，不按距离排序 |
| mm | 有效时整数 0～65535 毫米；非有效状态统一 -1 |
| age_ms | 距该路最后一次有效采样的毫秒数，饱和到 65535；从未有效也为 65535 |

快照一致读取三路缓存，不要求同步采样，不得阻塞等待传感器完成采集。

| 状态 | 含义 |
|---:|---|
| 0 VALID | 最新采集有效，且有效样本年龄不超过 200 ms |
| 1 RANGE_INVALID | 最新采集超量程 |
| 2 SIGNAL_INVALID | 最新采集信号质量不足 |
| 3 STALE | 采集未及时更新，有效样本超过 200 ms；已安装但启动后尚未采样也使用此状态 |
| 4 BUS_ERROR | 采集或总线错误 |
| 5 NOT_PRESENT | 未安装 |

未安装优先状态 5；明确采集错误保留对应错误状态，不能继续将历史值标为有效。age 始终按最后有效样本计算。

Android 仅在状态 0、距离合法、age_ms 加收到该快照后的经过时间不超过 200 ms 时使用该路数据。两端时钟不同，不能用手机时间直接减 emit_ms。无效、未知、过期均不等于无障碍。

## 4. 安装语义与保护

左、右传感器在车体两侧中部，手动调角后固定，目前朝正侧方，表示侧向距离，不能标注为左前／右前可通行通道。中路朝向在烧录联调时核对。安装角度、位置记录在配置或测试记录中，不逐帧传输；调角后更新记录。

本次仅升级遥测，不增加三路停车、避障或自动恢复规则，保留现有固件保护行为。侧方传感器不提供完整车头／车尾旋转扫掠区域覆盖。

## 5. 传输、队列与接收

- ASCII，每行最多 128 字节，包含 LF；接收端可忽略 CR。
- 默认 MTU 每个 Notify 最多 20 字节，不依赖 Android 增大 MTU。
- 同一行的分片连续有序，禁止与其他遥测或错误行的字节交织。
- 接收端缓存半行、循环提取多行；缺字段、非法数字、超长整行丢弃，重新同步至 LF。
- 固件非阻塞发送队列：待发送遥测最多保留一份最新快照，避免旧数据积压；正在发送的行完整结束后再选择下一行。
- 错误和配置回复优先于尚未发送的遥测。急停、电机保护立即本地执行，不等待遥测。
- 重连清空 Android 接收缓存及序号状态；重复或旧快照不刷新新鲜度。序号按模 65536 比较，前向差值 1～32767 为新快照，0 为重复，其余为旧包；新连接重新建立基线。

## 6. 黄金报文

以下各行实际均以 LF 结束；箭头仅为说明，不在线上传输。

```text
Android -> ESP32: f
ESP32 -> Android: fCART_AT8236:s:r3v1:
Android -> ESP32: s0
Android -> ESP32: !R3,100
ESP32 -> Android: !R3,OK,100
ESP32 -> Android: !R3D,0,15340,640,0,22,1350,0,18,610,0,25
ESP32 -> Android: !R3D,1,15440,-1,2,122,1340,0,18,605,0,25
ESP32 -> Android: !R3D,2,15540,-1,3,222,1330,0,18,-1,5,65535
Android -> ESP32: !R3,0
ESP32 -> Android: !R3,OK,0
```
