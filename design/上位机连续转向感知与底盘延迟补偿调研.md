# 上位机连续转向感知与底盘延迟补偿调研

更新时间：2026-08-31  
适用范围：OpenBot Android 上位机、Human Cart Simulator 与后续真实车低速跟随

## 1. 问题定义

当前真实小车的主要运动瓶颈不在“是否识别到人物”，而在命令实际变成车体运动的过程：

- 从停车到起步存在静摩擦、起步助推和轮速爬升延迟；
- 改变方向时，需要经历旧命令消退、轮子停转和新命令生效；
- 四个轮子的起转与减速不完全同步，连续直行指令也可能产生偏航；
- 人物框已快速移向画面边缘时，仅显示“左转 / 右转”无法说明转向是否来得及。

上位机不能在没有反馈的情况下精确补偿单个轮子，但可以先更完整地表达视觉侧的转向
需求，并记录其与后续底盘实测响应之间的关系。

## 2. 本轮实现：连续转向证据

Human Cart Simulator 新增 `SteeringDemandEstimator`。它不下发控制命令，只为页面、
日志和后续控制映射提供 `SteeringEvidence`。

### 2.1 输入与符号

输入为可信跟随阶段的目标 bbox、画面尺寸、手机方向、track ID、单调时间和预测提前量。
横向误差定义为：

```text
-1.0  目标在画面最左侧
 0.0  目标在画面中央
+1.0  目标在画面最右侧
```

方向文字以项目既有 `ControlGenerator.FLIP_TURN=true` 的控制口径为准：目标图像偏左时，
Simulator 显示向右转；目标图像偏右时，显示向左转。连续仪表与既有命令解释器共用该
口径，避免新旧页面出现相反的左右提示，并增加对称性测试。

### 2.2 平滑与预测

估计器使用常速度 alpha-beta 滤波：`alpha=0.55`、`beta=0.10`。输出平滑偏差和横移
速度，并按 `0 / 400 / 800 ms` 推测短期偏差。默认使用 `400 ms`，仅用于模拟器显示和
日志对比。

发生 track 切换、目标丢失或帧间隔超过 `500 ms` 时，估计器重置，避免旧人物或旧速度
影响当前判断。

### 2.3 从偏差到需求

需求百分比由两类证据取较大值：

1. 预测偏差离中心越远，需求越大；中心 `8%` 区域视为无转向需求。
2. 人物框距其移动方向对应的画面边缘不足画面宽度 `15%` 时，提高边缘紧迫度。

页面把结果分为居中、轻微、中等、大幅和接近边缘五档，并在档位边界使用约 `5%`
滞回，避免人员轻微晃动时文本反复跳变。

## 3. 页面与日志

Simulator 页面显示一个固定尺寸的转向仪表：

- 白色实心标记：滤波后的当前位置；
- 蓝色描边标记：预测位置；
- 主文字：方向、等级、需求百分比、当前偏差和预测偏差；
- 分段控件：`0 / 400 / 800 ms` 预测提前量。

安全动作优先于提示。当身份不确定、距离过近、受阻或目标丢失时，页面主提示仍为停车；
转向证据仅留在调试信息。诊断 CSV 在已有列的末尾追加原始偏差、平滑偏差、横移速度、
预测偏差、边缘紧迫度、需求、方向、等级和预测时域，不改变旧列顺序。

## 4. 为什么不直接修复小车偏航

人物框只描述目标相对手机的视觉位置，无法测得四个轮子是否已经以预期速度转动。若在
没有轮速或编码器反馈时给某一个轮子“猜一个补偿量”，可能在不同电量、地面摩擦和载重
条件下放大偏航。开环控制只能假定命令已被执行；要闭环校正，需要至少得到左右侧轮速、
车体里程计或其他可靠运动反馈。

因此，连续转向需求的近期价值是：提前发现目标快速接近画面边缘、降低急转时的前进
速度、减少不必要的“停住再转”。它不能单独解决起步延迟、轮间同步或真实车体曲率。

## 5. 后续验证与控制计划

1. 在 Human Cart Simulator 记录人物从中心缓慢横移、快速横移、停下与返回中心的日志，
   对比三档预测时域是否存在过冲或明显滞后。
2. 记录真实车的命令时间、开始运动时间、稳定直行时间和换向完成时间，得到可用的延迟
   范围，而不是凭主观感受设定预测时域。
3. 由下位机提供命令序号以及四轮或至少左右侧实际速度；上位机先用于状态显示和延迟
   量测，确认可靠后才考虑闭环准入或补偿。
4. 根据实测选取少量可可靠起转的低速差速档位。需求越大时优先降低前进速度；连续
   需求只负责选择档位或停车，不直接变成任意轮速。
5. 在空旷、低速、有人准备物理断电的条件下，先验证直行稳定和大半径缓弯；近场
   传感器接入前不进入货架拐角、拥挤区域或无人看护测试。

## 6. 参考资料与使用边界

- [Visual Predictive Control for Mobile Robots](https://doi.org/10.1016/j.compeleceng.2022.108120)：用于理解图像空间的短期预测控制思路；本项目采用的是更轻量的 alpha-beta 估计，不复现论文的完整控制器。
- [Nav2 Regulated Pure Pursuit Controller](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/controller_plugins/configuring_regulated_pp/)：参考“曲率增加时降低线速度”的工程原则；本项目尚未接入 Nav2。
- [ROS 2 diff_drive_controller](https://control.ros.org/jazzy/doc/ros2_controllers/diff_drive_controller/doc/userdoc.html)：参考差速控制中开环与速度反馈的区别；本项目当前尚未具备轮速反馈。
- [OpenCV KalmanFilter](https://docs.opencv.org/4.4.0/dd/d6a/classcv_1_1KalmanFilter.html)：参考状态估计接口概念；本轮未引入 OpenCV，滤波器采用纯 Java 实现。
